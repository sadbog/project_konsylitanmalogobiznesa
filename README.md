# 💼 Платформа для консультаций малого бизнеса

Веб-платформа для взаимодействия предпринимателей с бизнес-консультантами. Позволяет клиентам получать профессиональные консультации, управлять заказами и профилем, а консультантам и администраторам — эффективно управлять платформой.

---

## 📁 Структура проекта

```
/
├── index.html                  # Главная страница
├── login.html                  # Страница входа
├── register.html               # Регистрация
├── cart.html                   # Корзина услуг
├── cart-empty.html             # Корзина (пустая)
├── checkout.html               # Оформление заказа
├── client-dashboard.html       # Личный кабинет клиента
├── client-profile.html         # Профиль клиента
├── consultant-dashboard.html   # Кабинет консультанта
├── admin-dashboard.html        # Панель администратора
├── style.css                   # Основные стили
└── малый_бизнес.docx           # Документация проекта
```

---

## 👥 Роли пользователей

| Роль | Страница | Возможности |
|------|----------|-------------|
| **Клиент** | `client-dashboard.html` | Просмотр услуг, заказы, профиль |
| **Консультант** | `consultant-dashboard.html` | Управление запросами клиентов |
| **Администратор** | `admin-dashboard.html` | Полное управление платформой |

---

## 🚀 Как запустить

1. Скачай или клонируй репозиторий:
   ```bash
   git clone https://github.com/твой-юзернейм/название-репо.git
   ```

2. Открой `index.html` в браузере — никаких дополнительных зависимостей не требуется.

- **CSS3** — стилизация и адаптивная вёрстка (`style.css`)
